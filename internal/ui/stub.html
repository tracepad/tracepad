This build has no web interface

The API, the CLI and the MCP server are complete — only the browser interface is missing. It is compiled by Node and Vite, which a plain go build cannot run, so a source build ships without it.

Builds that carry the interface:

  • the release binaries, Homebrew and the Docker image;
  • a local make build, which builds the bundle first.

Meanwhile the API describes itself at GET /api/v1.
